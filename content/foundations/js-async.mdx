# Async Programming

Asynchronous programming is fundamental to modern JavaScript. Every API call, file read, or timeout uses async patterns.

## Promises

<SeniorNote>
In production, always return promises from async helpers so calling code can handle success and failure consistently.
</SeniorNote>

```javascript
// Creating a promise
const myPromise = new Promise((resolve, reject) => {
  setTimeout(() => {
    resolve("Success!");
  }, 1000);
});

// Consuming a promise
myPromise
  .then(result => console.log(result))
  .catch(error => console.error(error));
```

## Async/Await

```javascript
// Async function returns a promise
const fetchUser = async (userId) => {
  try {
    const response = await fetch(`/api/users/${userId}`);
    const data = await response.json();
    return data;
  } catch (error) {
    console.error("Failed to fetch user:", error);
    throw error;
  }
};

// Using it
const user = await fetchUser(1);
```

<ProTip>
Always use async/await over `.then()` chains. It's more readable and closer to synchronous code.
</ProTip>

## Error Handling

```javascript
const robustFetch = async (url) => {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    return await response.json();
  } catch (error) {
    console.error("Request failed:", error);
    // Handle or re-throw
  }
};
```

<Pitfall>
Swallowing errors in async code leads to silent failures. Always log and rethrow or return a clear error state.
</Pitfall>
