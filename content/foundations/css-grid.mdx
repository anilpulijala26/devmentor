# CSS Grid Layout

While Flexbox is excellent for aligning items in a single dimension (either a row OR a column), **CSS Grid** is a powerful layout system designed for two-dimensional grids—handling columns and rows at the same time.

---

## 1. Grid Container Basics

To define a grid, set `display: grid` on a container. You can establish columns and rows using the fractional (`fr`) unit, which represents a share of the available free space.

```css
.container {
  display: grid;
  
  /* Create three columns: 1st takes 200px, 2nd & 3rd share the rest equally */
  grid-template-columns: 200px 1fr 1fr;
  
  /* Create two rows of 100px and 200px */
  grid-template-rows: 100px 200px;
  
  /* Space between grid items */
  gap: 1.5rem;
}
```

---

## 2. Positioning Grid Items

Items inside a grid container can be positioned precisely using grid lines. Grid lines are 1-indexed boundary lines.

```
Grid Lines:
1          2          3          4
├──────────┼──────────┼──────────┤  Row Line 1
│  Item 1  │  Item 2  │  Item 3  │
├──────────┼──────────┼──────────┤  Row Line 2
│  Item 4  │  Item 5  │  Item 6  │
└──────────┴──────────┴──────────┘  Row Line 3
```

You can make an item span multiple columns or rows using `grid-column` and `grid-row` properties:

```css
.hero-item {
  /* Starts at column line 1, spans to column line 3 */
  grid-column: 1 / 3;
  
  /* Starts at row line 1, spans to row line 2 */
  grid-row: 1 / 2;
}

/* Shorthand using span keyword */
.sidebar {
  grid-column: span 1; /* Spans 1 column track */
  grid-row: span 2;    /* Spans 2 row tracks */
}
```

---

## 3. Responsive Auto-Fitting Templates

One of Grid's best features is building responsive layouts *without* writing `@media` queries. This is achieved using `repeat`, `minmax`, and auto-placement keywords:

* **`auto-fill`**: Fills the row with as many columns as will fit, even if they are empty.
* **`auto-fit`**: Fills the row with columns, and stretches them to take up any empty space.

```css
.responsive-card-grid {
  display: grid;
  /* Columns will be at least 250px, but will grow to share space equally */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 2rem;
}
```

---

## 4. Grid Template Areas

For page layouts, `grid-template-areas` provides a readable way to arrange elements:

```css
.page-layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  height: 100vh;
}

header { grid-area: header; }
aside { grid-area: sidebar; }
main { grid-area: main; }
footer { grid-area: footer; }
```

## 5. Flexbox vs. CSS Grid

To choose the right layout tool, follow these guidelines:

| Property | Flexbox | CSS Grid |
| :--- | :--- | :--- |
| **Dimension** | 1D Layout (Row or Column) | 2D Layout (Row AND Column) |
| **Approach** | Content-first (items size themselves) | Layout-first (container defines tracks) |
| **Alignment** | Along a single main axis | Across intersection cell tracks |
| **Use Case** | Navbars, buttons lists, simple forms | Dashboard panels, card grids, full page templates |

<SeniorNote>
Do not view Flexbox and Grid as competitors. Production apps combine both: use CSS Grid to layout the main panels of a page or page grids, and Flexbox to align text and buttons inside those individual grid panels.
</SeniorNote>

<Pitfall>
When using auto-placement (like <code>repeat(auto-fit, ...)</code>), be careful with padding and borders. If they cause grid items to exceed the container width, elements will wrap unexpectedly. Always use <code>box-sizing: border-box</code> globally.
</Pitfall>

## Key Takeaways

* **CSS Grid** defines rows and columns concurrently, making complex structures predictable.
* **Auto-fit combined with minmax()** automates desktop-to-mobile layouts.
* **Fractional units (`fr`)** distribute empty container space proportionally.
* **Flexbox and Grid** work best together to structure layout sections.
