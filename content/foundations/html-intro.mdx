## What is HTML?

HTML is a markup language—not a programming language. It tells browsers how to display content through a system of tags and elements. Think of it as the blueprint of a house; CSS is the decoration, and JavaScript is the functionality.


<SeniorNote>
HTML has been around since 1991, but semantic HTML is relatively new in mainstream practice. Many production sites still use divs everywhere—don't follow that pattern. Use semantic HTML from day one.
</SeniorNote>

## The Basic Structure

Every HTML document follows this structure:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
  </head>
  <body>
    <h1>Welcome to my page</h1>
  </body>
</html>
```

### Breaking It Down

- **`<!DOCTYPE html>`** – Tells the browser this is HTML5
- **`<html lang="en">`** – Root element with language attribute (accessibility matter)
- **`<head>`** – Contains metadata, title, stylesheets
- **`<body>`** – Contains all visible content

<Pitfall>
Forgetting the `lang` attribute on the `<html>` tag. This affects screen readers and SEO. Always include it.
</Pitfall>

## Common Elements

### Headings

```html
<h1>Main heading</h1>
<h2>Subheading</h2>
<h3>Sub-subheading</h3>
```

Use headings semantically—one `<h1>` per page, in logical order.

### Paragraphs and Text

```html
<p>This is a paragraph.</p>
<strong>This is important text.</strong>
<em>This text is emphasized.</em>
<small>This text is secondary.</small>
```

### Lists

```html
<!-- Unordered list -->
<ul>
  <li>Item one</li>
  <li>Item two</li>
</ul>

<!-- Ordered list -->
<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>
```

### Links

```html
<a href="/example">Visit Example</a>
<a href="/about">About Us</a>
```

<ProTip>
Always use meaningful link text, not "click here". Screen readers and SEO depend on descriptive anchor text.
</ProTip>

## Metadata Matters

The `<head>` section doesn't display on the page, but it's crucial:

```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Description for search engines">
  <title>Your Page Title</title>
  <link rel="stylesheet" href="styles.css">
</head>
```

The `viewport` meta tag ensures your site works on mobile devices. This is non-negotiable in 2026.

## Key Takeaways

- HTML provides **structure and meaning** to content
- **Semantic HTML** makes your pages accessible and SEO-friendly
- Proper meta tags are essential for mobile and search engines
- Use headings, lists, and elements for their intended purpose
