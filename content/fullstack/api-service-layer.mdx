## Why This Matters in Real Projects

Scattering raw fetch calls throughout UI components makes modifications difficult. Designing a structured API service layer keeps API paths organized and handles authorization token injections automatically.

<SeniorNote>
Use Axios interceptors to automatically append authorization headers to requests, and intercept response errors to trigger automatic token refresh flows.
</SeniorNote>

---

## Concept Explanation

### Service Layers & Auth Routing

- **Service Module**: Centralizes API query definitions.
- **Interceptors**: Middleware functions that intercept request and response pipelines.
- **Auth Routing**: Client-side routing checks that redirect unauthenticated users to login screens.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Axios client API service layer with auth interceptors
import axios from 'axios';

const apiClient = axios.create({
  baseURL: '/api/v1',
  headers: { 'Content-Type': 'application/json' }
});

// Intercept request to add auth token headers
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('accessToken');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
}, (error) => {
  return Promise.reject(error);
});

export const userService = {
  getProfile: async () => {
    const res = await apiClient.get('/users/profile');
    return res.data;
  }
};
```

## Interview Tip

<InterviewTip question={"How do you handle token expiration in the client?"}>
Use an Axios response interceptor that catches 401 Unauthorized errors, requests a new access token using a refresh token, updates authorization headers, and retries the original request.
</InterviewTip>
