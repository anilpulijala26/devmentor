## Why This Matters in Real Projects

Un-optimized web assets result in slow load times and poor search engine rankings. Correctly configuring SEO tags, robots.txt, and enforcing SSL redirects improves site visibility and security.

<SeniorNote>
Use Let's Encrypt or Cloudflare to enforce SSL redirects (HTTP to HTTPS) at edge gateways to protect user data transit channels.
</SeniorNote>

## Concept Explanation

### Metadata, SSL & Performance

- **robots.txt**: Directs search engine crawlers on which pages to index or skip.
- **SSL Certificates**: Encrypts data in transit between clients and servers.
- **Bundle Optimization**: Minifies bundles, defers non-critical scripts, and optimizes layouts to improve Web Vital metrics.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// robots.txt and sitemap.xml configuration examples
# robots.txt
User-agent: *
Allow: /
Disallow: /admin
Disallow: /api/

Sitemap: https://codenivra.com/sitemap.xml

# sitemap.xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://codenivra.com/</loc>
    <lastmod>2026-06-02</lastmod>
    <changefreq>monthly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
```

## Interview Tip

<InterviewTip question={"What is the difference between A records and CNAME records in DNS?"}>
A records map domain names directly to static IP addresses (e.g. 192.0.2.1). CNAME records map domains to other domain names (e.g. app.vercel.sh), allowing endpoints to handle IP drifts automatically.
</InterviewTip>
