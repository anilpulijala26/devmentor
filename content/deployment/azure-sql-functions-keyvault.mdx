---

## Why This Matters in Real Projects

Exposing secrets or leaving databases open is a major security risk. Encrypting keys in Key Vault and running serverless APIs manages security and controls resources.

<SeniorNote>
Use Key Vault references in App Services to load secrets dynamically from the vault on server boot, keeping configurations out of code.
</SeniorNote>

## Concept Explanation

### Azure SQL, Functions & Security

- **Azure SQL Database**: Managed relational database engine based on Microsoft SQL Server.
- **Azure Functions**: Serverless compute service that runs code on demand in response to events.
- **Azure Key Vault**: Secure storage for encrypting keys, secrets, and certificates.

## Interview Tip

<InterviewTip question={"Why should you store environment secrets in Key Vault?"}>
Key Vault encrypts secrets at rest, manages access permissions using policy rules, and provides audit logs of secret access, keeping credentials secure.
</InterviewTip>
