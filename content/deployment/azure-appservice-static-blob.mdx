## Why This Matters in Real Projects

Azure is standard in enterprise environments. Deploying applications onto App Services and storing uploads in Blob Storage provides security, scalability, and integration with active directory tools.

<SeniorNote>
Use Azure Managed Identities to authorize App Services to query Blob Storage, avoiding storing connection keys in environment configs.
</SeniorNote>

## Concept Explanation

### Azure Cloud Architectures

- **Azure App Service**: Managed PaaS hosting for backend APIs and web applications.
- **Azure Blob Storage**: Object storage service for storing unstructured binary data (files).
- **Managed Identity**: Secure credentials management that allows cloud resources to authenticate without credentials files.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Uploading streams to Azure Blob Storage
import { BlobServiceClient } from '@azure/storage-blob';
import { DefaultAzureCredential } from '@azure/identity';

// Use Managed Identity credentials
const blobServiceClient = new BlobServiceClient(
  'https://codenivrastorage.blob.core.windows.net',
  new DefaultAzureCredential()
);

export async function uploadBlob(containerName, blobName, buffer) {
  const containerClient = blobServiceClient.getContainerClient(containerName);
  const blockBlobClient = containerClient.getBlockBlobClient(blobName);
  
  await blockBlobClient.upload(buffer, buffer.length);
  return blockBlobClient.url;
}
```

## Interview Tip

<InterviewTip question={"What is an Azure Managed Identity?"}>
Azure Managed Identity is an identity configuration created in Microsoft Entra ID. It allows cloud resources (like App Services) to authenticate with other secure resources (like Blob Storage) without storing credentials.
</InterviewTip>
