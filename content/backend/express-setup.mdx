## Why This Matters in Real Projects

Express is the enterprise standard routing framework for Node.js. Establishing modular router tables ensures clean codebase scaling, and correct route variables configurations prevent parameter overrides.

<SeniorNote>
Always group routes logically using `express.Router()` sub-routers. Do not attach all routes directly to the main server instance. Use process environment variables to configure port mappings dynamically.
</SeniorNote>

---

## Concept Explanation

### Express Routing Mechanics

Express maps incoming HTTP requests (HTTP Method + URL Path) to specific controller handler functions:
- **Port Binding**: Binds server processes to network interfaces (e.g. `PORT=5000`).
- **Route Parameters**: Placeholders inside URL routes to match dynamic inputs, compiled into `req.params` (e.g. `/users/:id`).
- **Query Parameters**: Key-value query parameters appended to URLs, compiled into `req.query` (e.g. `/search?q=node`).

## Code Example

Below is a configuration file matching senior standards:

```javascript
import express from 'express';
const app = express();
const router = express.Router();

app.use(express.json()); // Middleware to parse incoming JSON bodies

// Router definitions
router.get('/products/:id', (req, res) => {
  const productId = req.params.id; // Reading route parameter
  const searchLimit = req.query.limit; // Reading query parameter
  
  res.status(200).json({
    id: productId,
    limit: searchLimit || 'default',
    timestamp: new Date().toISOString()
  });
});

app.use('/api/v1', router);

const PORT = process.env.PORT || 5000;
app.listen(PORT, () => {
  console.log(`Server is operating on port ${PORT}`);
});
```

## Common Mistakes

Here is an example of incorrect setups vs clean, optimized configurations.

<CommonMistake
  title={"Incorrect Route Ordering and Overlaps"}
  badDesc={"Placing dynamic route parameters before static sub-routes. The dynamic parameter greedily matches first, short-circuiting static routes."}
  badCode={"// BAD: Dynamic ID matches first\napp.get('/users/:id', (req, res) => { ... });\napp.get('/users/active', (req, res) => { ... }); // NEVER REACHED!"}
  goodDesc={"Placing specific static routes before dynamic parameters."}
  goodCode={"// GOOD: Static route evaluated first\napp.get('/users/active', (req, res) => { ... });\napp.get('/users/:id', (req, res) => { ... });"}
/>

## Interview Tip

<InterviewTip question={"What does express.json() middleware do?"}>
express.json() is a built-in middleware in Express that parses incoming HTTP requests with JSON payloads. It reads the raw request stream, parses it as JSON, and mounts the parsed object directly onto the Request object as 'req.body' for subsequent route handlers to read.
</InterviewTip>
