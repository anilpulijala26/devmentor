## Why This Matters in Real Projects

Exposed API endpoints are vulnerable to request spamming and brute-force attacks. Implementing rate limiters and input sanitizers blocks malicious requests, protecting server resources and database records.

<SeniorNote>
Use rate limiters globally to throttle traffic, but define stricter rate limits on sensitive endpoints like login and registration forms.
</SeniorNote>

---

## Concept Explanation

### Input Throttling & Sanitization

- **Rate Limiting**: resticts the number of requests an IP can send within a timeframe.
- **Input Sanitization**: Parses request bodies and query parameters to strip out executable script tags, preventing XSS and SQL injection attacks.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Throttling traffic using Express Rate Limit middlewares
import express from 'express';
import rateLimit from 'express-rate-limit';
import DOMPurify from 'isomorphic-dompurify';

const app = express();
app.use(express.json());

// 1. Configure global rate limiting middleware
const globalLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15 Minutes
  max: 100, // Limit each IP to 100 requests per window
  message: { error: 'Too many requests. Please try again later.' }
});
app.use(globalLimiter);

// 2. Input Sanitization middleware
const sanitizeInput = (req, res, next) => {
  if (req.body) {
    for (const key in req.body) {
      if (typeof req.body[key] === 'string') {
        req.body[key] = DOMPurify.sanitize(req.body[key]); // Strip XSS scripts
      }
    }
  }
  next();
};

app.post('/api/comments', sanitizeInput, (req, res) => {
  res.json({ comment: req.body.comment });
});
```

## Interview Tip

<InterviewTip question={"How do you handle rate limiting in multi-instance load-balanced environments?"}>
In multi-instance environments, local memory rate limiters will not track requests across instances. You should use a centralized data store (like Redis) to share request counters across backend server instances.
</InterviewTip>
