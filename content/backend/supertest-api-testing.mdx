## Why This Matters in Real Projects

Testing API routes manually using client tools is slow. Writing automated integration tests using Supertest sends mock HTTP requests to routes, asserting response values and database updates on every build.

<SeniorNote>
Expose your Express `app` instance from your entrypoint without calling `app.listen()`. This allows Supertest to query the server in memory without binding network ports, speeding up tests.
</SeniorNote>

## Concept Explanation

### Route Integration Testing

- **Supertest**: A testing library used to query Express HTTP routes in memory, asserting responses.
- **In-Memory Assertions**: Supertest routes requests through the Express application stack, verifying authentication, validation, controllers, and error middlewares.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Integration testing Express routes using Supertest
import request from 'supertest';
import express from 'express';

const app = express();
app.use(express.json());

app.post('/api/v1/echo', (req, res) => {
  res.status(200).json({ message: req.body.message });
});

// Jest integration test suite
describe('POST /api/v1/echo integration tests', () => {
  it('returns a 200 status and echoes the request message', async () => {
    const response = await request(app)
      .post('/api/v1/echo')
      .send({ message: 'Hello World' })
      .set('Accept', 'application/json');
      
    expect(response.status).toBe(200);
    expect(response.body.message).toBe('Hello World');
  });
});
```

## Common Mistakes

Here is an example of incorrect setups vs clean, optimized configurations.

<CommonMistake
  title={"Hardcoding API hosts in integration tests"}
  badDesc={"Making actual network requests to live servers in integration tests, which makes tests dependent on network connectivity and server availability."}
  badCode={"// BAD: Queries live staging URL\nconst res = await request('https://staging.api.com').get('/users');"}
  goodDesc={"Querying the Express app instance in memory using Supertest."}
  goodCode={"// GOOD: Queries local Express instance in memory\nconst res = await request(app).get('/users');"}
/>
