## Why This Matters in Real Projects

Storing user uploads on local server disks is not scalable, as instances are frequently replaced. Storing files in specialized cloud storage (like AWS S3 or Supabase Storage) ensures persistent and scalable asset management.

<SeniorNote>
Never write AWS credentials directly inside code repositories. Use IAM roles or load credentials from environment variables dynamically.
</SeniorNote>

---

## Concept Explanation

### Cloud Storage Integrations

- **Cloud Buckets**: Persistent, scalable cloud storage containers (like AWS S3 or Supabase Storage).
- **Streaming Uploads**: Transfers file buffers from memory directly to cloud storage endpoints, avoiding local disk writes.
- **Bucket Policies**: Configures security permissions, restricting access to public or private storage resources.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Streaming files to AWS S3 using S3 SDK client
import { S3Client, PutObjectCommand } from '@aws-sdk/client-s3';
import express from 'express';
import multer from 'multer';

const app = express();
const upload = multer({ storage: multer.memoryStorage() });

const s3 = new S3Client({
  region: process.env.AWS_REGION
});

app.post('/api/upload', upload.single('doc'), async (req, res, next) => {
  try {
    const file = req.file;
    
    const uploadParams = {
      Bucket: process.env.AWS_S3_BUCKET,
      Key: `documents/${Date.now()}-${file.originalname}`,
      Body: file.buffer, // Stream binary buffer
      ContentType: file.mimetype
    };
    
    await s3.send(new PutObjectCommand(uploadParams));
    res.json({ success: true, path: uploadParams.Key });
  } catch (err) {
    next(err);
  }
});
```

## Interview Tip

<InterviewTip question={"Why should production backends use IAM roles instead of API credentials?"}>
API credentials must be stored and rotated, creating security risks. IAM roles grant temporary credentials dynamically to cloud resources, eliminating the need to store static keys.
</InterviewTip>
