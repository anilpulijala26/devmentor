## Why This Matters in Real Projects

Exposed keys and SQL injection vulnerabilities represent major security gaps. Understanding security best practices and securing variables helps prevent credentials leaks and server intrusions.

<SeniorNote>
Never check in `.env` files into source control repositories. Use vault storage systems in production (like AWS Secrets Manager, Azure Key Vault, or HashiCorp Vault) to inject variables safely.
</SeniorNote>

## Concept Explanation

### OWASP Security Fundamentals

- **Broken Access Control**: Ensure users can only access records they own.
- **Cryptographic Failures**: Encrypt sensitive data in transit and at rest.
- **Injection**: Prevent SQL and NoSQL injections by parameterizing queries.
- **Security Misconfiguration**: Deactivate debug error panels and default configuration options in production.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Query parameterization to prevent SQL injection vulnerabilities
import express from 'express';
import pg from 'pg';
const pool = new pg.Pool();
const app = express();

// BAD: String concatenation is vulnerable to SQL injection!
app.get('/users-bad', async (req, res) => {
  const query = `SELECT * FROM users WHERE email = '${req.query.email}'`;
  const result = await pool.query(query); // Vulnerable to SQL injection!
  res.json(result.rows);
});

// GOOD: Parameterized queries sanitize inputs natively
app.get('/users-good', async (req, res) => {
  const query = 'SELECT * FROM users WHERE email = $1';
  const result = await pool.query(query, [req.query.email]); // Safe query parameters
  res.json(result.rows);
});
```

## Interview Tip

<InterviewTip question={"What is SQL Injection and how do you prevent it?"}>
SQL Injection is a vulnerability where attackers inject malicious SQL statements into inputs, causing databases to execute unauthorized commands. Prevent it by using parameterized queries or ORMs, which sanitize inputs and treat values as data rather than executable code.
</InterviewTip>
