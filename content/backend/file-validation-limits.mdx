## Why This Matters in Real Projects

Exposing private files (like invoices or user contracts) via public URLs is a major security gap. Generating short-lived, pre-signed download URLs secures assets while granting access to authorized users.

<SeniorNote>
Always set a short expiration time (e.g. 5-15 minutes) on pre-signed URLs to prevent users from sharing links publicly.
</SeniorNote>

---

## Concept Explanation

### Upload Security & Pre-Signed URLs

- **Content-Type Checks**: Enforces type validations on the backend to prevent users from uploading malicious executable scripts disguised as images.
- **Pre-Signed URLs**: Generates short-lived, authenticated URLs that grant temporary access to private S3 bucket resources without exposing credentials.

## Code Example

Below is a configuration file matching senior standards:

```javascript
// Generating S3 pre-signed download URLs
import { S3Client, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

const s3 = new S3Client({ region: 'us-east-1' });

export async function generateDownloadLink(fileKey) {
  const command = new GetObjectCommand({
    Bucket: process.env.AWS_S3_BUCKET,
    Key: fileKey
  });
  
  // Generate pre-signed URL valid for 15 minutes
  const url = await getSignedUrl(s3, command, { expiresIn: 900 });
  return url;
}
```

Here is an example of incorrect setups vs clean, optimized configurations.

## Interview Tip

<InterviewTip question={"How do you verify the true file type of an upload on the server?"}>
Do not rely on the file extension. Read the first few bytes of the file (the magic numbers) to identify the file signature, or use validation libraries like file-type to verify MIME properties.
</InterviewTip>
